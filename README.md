# Projeto-Agendamento-Tecnico
Passos para a execução do sistema:


1. Criação do banco de dados

   
   1.1 Copiar e executar os comandos dentro do arquivo BancoDeDados.txt dentro do phpMyAdmin;

   
2. Criação do usuário Admin

   
   2.1 Executar o arquivo criar_admin.php dentro da pasta scripts da seguinte forma:
   

      2.1.1 Digite na url o seguinte caminho: localhost/agendamento_tecnico/scripts/criar_admin.php;
   

      2.1.2 Se aparecer uma página em branco com a seguinte frase: "Administrador criado com sucesso! 🚀", o usuário admin foi criado com sucesso;
